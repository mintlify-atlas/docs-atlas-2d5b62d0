---
title: "Setting Up Giscus Comments in TanaFlows Ghost Theme"
sidebarTitle: "Giscus"
description: "Integrate GitHub Discussions-powered comments into TanaFlows using Giscus — ideal for developer audiences who already have a GitHub account."
---

[Giscus](https://giscus.app/) provides a seamless way to integrate GitHub-based comments directly into your website. It uses GitHub Discussions as the backend, so readers authenticate with their existing GitHub account. Here's how you install Giscus into the TanaFlows theme.

<Steps>
  <Step title="Generate your Giscus configuration">
    Follow the [Giscus setup guide](https://giscus.app/) to generate your configuration. You will need:

    1. A [GitHub](https://github.com/) account with a newly created public repository.
    2. The Giscus app granted permission to access your repository.
    3. The Discussions feature enabled on your repository.

    After completing setup, you will obtain a configuration script that looks like this:

    ```html
    <script
      src="https://giscus.app/client.js"
      data-repo="[ENTER REPO HERE]"
      data-repo-id="[ENTER REPO ID HERE]"
      data-category="[ENTER CATEGORY NAME HERE]"
      data-category-id="[ENTER CATEGORY ID HERE]"
      data-mapping="pathname"
      data-strict="0"
      data-reactions-enabled="1"
      data-emit-metadata="0"
      data-input-position="bottom"
      data-theme="preferred_color_scheme"
      data-lang="en"
      crossorigin="anonymous"
      async
    ></script>
    ```

    Write down these four important attributes for the next step:

    - `data-repo`
    - `data-repo-id`
    - `data-category`
    - `data-category-id`

    <Note>
      The values shown above are placeholders. Your generated config will contain real strings.
    </Note>
  </Step>

  <Step title="Select Giscus as the comment provider in Ghost">
    In your Ghost Admin dashboard, go to **Settings** → **Design & branding** → **Customizer** → **Post** → **Comment provider** and choose **Giscus**.
  </Step>

  <Step title="Paste the four data attributes into the Comment ID field">
    In the **3rd comment id** field, paste all four attributes on a **single line**, separated by spaces:

    ```text
    data-repo="[ENTER REPO HERE]" data-repo-id="[ENTER REPO ID HERE]" data-category="[ENTER CATEGORY NAME HERE]" data-category-id="[ENTER CATEGORY ID HERE]"
    ```

    A real example looks like this:

    ```text
    data-repo="CuongGhost/giscus" data-repo-id="MDExxxx2MDc1MDA=" data-category="Announcements" data-category-id="DIC_kwDxxx"
    ```
  </Step>

  <Step title="Save and verify">
    Click **Save** in the Customizer, then open any post on your site. The Giscus comment widget should appear at the bottom of the post.
  </Step>
</Steps>
