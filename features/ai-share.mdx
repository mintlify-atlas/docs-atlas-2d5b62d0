## Copy as Markdown

Most modern note-taking and knowledge-management tools — Obsidian, Notion, Bear, and AI chatbot windows — use **Markdown** as their standard input format.

**The problem with manual copying:** Selecting and copying text from a browser typically breaks formatting, loses image links, scrambles tables, and leaves clean text cluttered with HTML artifacts.

**The TanaFlows solution:** A single click on the **"Copy as Markdown"** button compiles the entire article into clean, standard Markdown syntax, including:

- Titles, headings (H1–H6), blockquotes, and ordered/unordered lists.
- Original formatting — bold, italic, hyperlinks, and inline images — preserved accurately.
- **Frontmatter Metadata:** Author information, publish date, tags, description, and the original article URL are automatically prepended in YAML format at the top of the copied content.

The YAML frontmatter makes the copied content immediately useful for saving to a personal knowledge base (Second Brain) or pasting as rich context into an AI conversation — no manual cleanup required.

### Pre-loaded System Prompt

Clicking any of the three AI buttons opens the chat window with the following optimized prompt already entered:

```text
Read [Article URL] so I can ask questions about it.
```

The exact URL of the current article is substituted automatically — no manual copy-pasting needed.

### Key Benefits for Readers

- **Instant Summaries:** As soon as the chatbot opens, readers can immediately type a follow-up like *"Summarize the 3 key points of this article"* without any setup.
- **Deep-Dive Conversations:** Readers can ask the AI to explain complex technical concepts from the article, challenge assumptions, or explore related topics.
- **No Manual Copy-Pasting:** The article URL is embedded directly in the opening prompt, allowing the AI to scan the page accurately from the first message.
