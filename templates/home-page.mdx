The TanaFlows homepage uses the **`home-1.hbs`** layout — a modern, SEO-optimised design built for fast page loads. Rather than editing theme source files, all homepage sections (hero, products shelf, testimonials, gift callout, and featured posts) are driven by lightweight JavaScript configuration blocks injected through Ghost's built-in Code Injection panel. The four-step process below takes you from a fresh Ghost installation to a fully populated landing page.

---

## Step 1: Configure `routes.yaml`

The homepage requires a custom route entry that maps the root path (`/`) to a static Ghost page named `home` and renders it with the `home-1` template.

<Steps>
  <Step title="Download your current routes file">
    Go to **Ghost Admin → Settings → Labs**, find the **Routes** section, and click **Download current routes.yaml**.
  </Step>
  <Step title="Edit the routes block">
    Open the file in any text editor and add or replace the `routes:` block with:

    ```yaml
    routes:
      /:
        data: page.home
        template: home-1
    ```
  </Step>
  <Step title="Upload the updated file">
    Save the file and upload it back in Ghost Admin under **Settings → Labs → Routes**.
  </Step>
</Steps>

---

## Step 2: Create the Homepage Static Page

This Ghost Page provides the hero title, hero subtitle, feature image background, and body copy displayed in the middle of the landing page.

<Steps>
  <Step title="Create a new Page">
    Go to **Ghost Admin → Pages → New Page**.
  </Step>
  <Step title="Fill in the page content">
    - **Title** — Your main headline or slogan (displayed prominently in the hero).
    - **Body** — Any introductory text you want shown in the centre of the page.
  </Step>
  <Step title="Configure page settings">
    Open the gear icon (⚙️) in the top-right corner and set:
    - **Page URL (Slug):** `home` — this must match `page.home` in `routes.yaml`.
    - **Feature Image:** Upload a large image; it becomes the hero section background.
    - **Excerpt:** A short line displayed as a subheading beneath the main title.
  </Step>
  <Step title="Publish the page">
    Click **Publish**.
  </Step>
</Steps>

## Step 3: Configure Widgets via Code Injection

Open the **`home`** page settings (gear icon) → **Code Injection** → paste the relevant `<script>` blocks into the **Page header** field. You can include all six widgets or only the sections you need.

<Note>
  After pasting any script, customise the texts, image URLs, and links to match your brand before clicking **Save**.
</Note>

### Widget 1 — Highlight Logic

Automatically highlights specified keywords in homepage headings using the theme's brand colour.

```html
<script>
window.homeData = () => ({
  init() {
    if (!Alpine.store('home')) {
      Alpine.store('home', {
        core: Tana.persist({
          // Words or phrases to highlight in orange
          highlights: ['Stop hoarding', 'do not know where to start?'],
          cache: {}
        }).as('home_core').using(sessionStorage)
      });
    }
  },
  highlight(text) {
    if (!text) return text;
    const store = Alpine.store('home');
    if (!store || !store.core) return text;
    if (store.core.cache[text]) return store.core.cache[text];
    const highlights = store.core.highlights;
    if (!highlights || !Array.isArray(highlights)) return text;
    const escaped = highlights.map(w => w.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'));
    const regex = new RegExp(`(${escaped.join('|')})`, 'gi');
    const result = text.replace(regex, '<span class="text-ghost">$1</span>');
    store.core.cache[text] = result;
    return result;
  }
});
</script>
```

## Step 4: Add Featured Posts

The **Featured Articles** section at the bottom of the homepage automatically pulls posts you have marked as featured in Ghost Admin.

<Steps>
  <Step title="Open a post">
    Go to **Ghost Admin → Posts** and select the post you want to feature.
  </Step>
  <Step title="Mark it as featured">
    Open post settings (gear icon) and enable **Feature this post** (star icon).
  </Step>
  <Step title="Save">
    Click **Save**. The post will appear automatically in the homepage featured section.
  </Step>
</Steps>
