TanaFlows includes a dedicated **Course** page template that transforms any Ghost page into a fully featured video course hub — complete with a lesson sidebar, progress tracking, and a video player. The template works with seven major video platforms, and you select the platform simply by assigning a single internal tag to the page. Lesson data is injected via a `window.lessons` JavaScript array inside a Ghost HTML card, so you never need to touch theme files.

---

## Step 1: Create the Course Page

<Steps>
  <Step title="Create a new Page in Ghost Admin">
    Go to **Ghost Admin → Pages → New Page**. Using a Page (rather than a Post) is recommended so the course does not appear in your blog feed.
  </Step>
  <Step title="Select the Course template">
    Open page settings (gear icon ⚙️) and set the **Template** field to **`Course`**.
  </Step>
  <Step title="Assign a platform tag">
    In the **Tags** field, add the internal tag that matches your video hosting platform:

    | Platform | Tag to assign |
    |----------|---------------|
    | YouTube  | `#youtube`    |
    | Vimeo    | `#vimeo`      |
    | BunnyCDN | `#bunny`      |
    | HTML5 / MP4 | `#htmlvideo` |
    | Alugha   | `#alugha`     |
    | Mux      | `#mux`        |
    | Loom     | `#loom`       |

  </Step>
  <Step title="Add the hero content">
    Fill in the page **Title**, **Feature Image**, and **Excerpt** as usual. The excerpt appears as a short description beneath the course title.
  </Step>
</Steps>

## Step 2: Inject the Lesson List via HTML Card

The course player reads its lesson list from a global JavaScript variable called `window.lessons`. You define this array inside a **Ghost HTML card** in the page editor — no plugin or external service is required.

<Note>
  In the Ghost editor, click the **+** icon and choose the **HTML** card. Paste the appropriate script block from the platform tabs below directly into that card.
</Note>

<Tabs>
  <Tab title="YouTube">
    For YouTube, `videoUrl` is the **11-character Video ID** found in the URL.

    ```javascript
    <script>
        window.lessons = [
            {
                "title": "Lesson 1: Orientation",
                "videoUrl": "WqASI-p-dJM"
            },
            {
                "title": "Lesson 2: Everything is a Node",
                "videoUrl": "v6C7t6l8iL4"
            },
            {
                "title": "Lesson 3: Data about Nodes",
                "videoUrl": "f4FcNhlU7G4"
            },
            {
                "title": "Lesson 4: Search in Tana",
                "videoUrl": "ohisZOdNNFY"
            },
            {
                "title": "Lesson 5: Supertag Basics",
                "videoUrl": "JPxYt1RNB7E"
            },
            {
                "title": "Lesson 6: Supertag + Search",
                "videoUrl": "2O_-l_RAr9Q"
            }
        ];
    </script>
    ```

    **How to find your YouTube Video ID:**

    | URL format | Example | Video ID location |
    |---|---|---|
    | `youtube.com/watch?v=` | `…watch?v=8XoSspXg2iU&list=…` | Characters after `v=` → `8XoSspXg2iU` |
    | `youtu.be/` | `https://youtu.be/dQw4w9WgXcQ` | Characters after `/` → `dQw4w9WgXcQ` |
    | `youtube.com/embed/` | `…/embed/FfJ4m75v0zU` | Characters after `/embed/` → `FfJ4m75v0zU` |

    The Video ID is always an **11-character string** of letters, numbers, hyphens, or underscores.
  </Tab>

## Step 3: Add a Course Introduction for SEO

After the HTML card containing `window.lessons`, continue writing in the Ghost editor as normal. Any body content you add to the page will render as an **Introduction** section below the video player. This long-form content is indexed by search engines and can significantly improve organic discovery of your course page.

<Tip>
  Write a thorough introduction — cover what students will learn, prerequisites, and who the course is for. This content is the primary SEO signal for the page since the video itself is not crawlable.
</Tip>
